# AlleFarben Alltagshilfe — Website UI Kit

A React/JSX recreation of the marketing website. Open `index.html` in a browser; it runs in-place.

## Components

- `Navbar.jsx` — translucent sticky nav with rainbow underline
- `Hero.jsx` — split hero with photo + claim + CTAs
- `ServiceCards.jsx` — 3-pillar grid (Haushalt / Begleitung / Pflegefachwissen)
- `FounderBlock.jsx` — Andreas intro block with script accent
- `Testimonial.jsx` — single testimonial with photo + quote
- `CTABlock.jsx` — yellow full-bleed CTA
- `Footer.jsx` — dark footer with rainbow top edge
- `Button.jsx` / `Pill.jsx` / `Section.jsx` — primitives

## Click-thru

The "Termin buchen" CTA opens a 2-step inline booking sheet (fake — no backend). You can change the selected service pill; the copy updates live.

## Design source

This is a recreation based on the provided brand materials: logos, photography, color direction (`#ffe28d` primary, rainbow gradient), and voice examples. No codebase or Figma was attached — the marketing site was built from the brand direction. **Please send the live site URL or a codebase if you have one**, so the UI kit can mirror the real thing.
